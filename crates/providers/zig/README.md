# crossbuild-provider-zig

Zig toolchain provider leveraging zig cc as a cross-compiler

Part of the [cargo-crossbuild](https://github.com/Moon9t/cargo-crossbuild) workspace — a Cargo-native cross-compilation toolchain manager.

## Installation

`	oml
[dependencies]
crossbuild-provider-zig = "1.0.0"
`
