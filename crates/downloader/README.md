# crossbuild-downloader

HTTP downloader with caching and integrity verification for toolchain artifacts

Part of the [cargo-crossbuild](https://github.com/Moon9t/cargo-crossbuild) workspace — a Cargo-native cross-compilation toolchain manager.

## Installation

`	oml
[dependencies]
crossbuild-downloader = "1.0.0"
`
