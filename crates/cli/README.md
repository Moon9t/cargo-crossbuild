# cargo-crossbuild-cli

CLI frontend for cargo-crossbuild, the cross-compilation toolchain manager

Part of the [cargo-crossbuild](https://github.com/Moon9t/cargo-crossbuild) workspace — a Cargo-native cross-compilation toolchain manager.

## Installation

`	oml
[dependencies]
cargo-crossbuild-cli = "1.0.0"
`
