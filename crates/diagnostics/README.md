# crossbuild-diagnostics

Diagnostic reporting and health checks for cross-compilation setups

Part of the [cargo-crossbuild](https://github.com/Moon9t/cargo-crossbuild) workspace — a Cargo-native cross-compilation toolchain manager.

## Installation

`	oml
[dependencies]
crossbuild-diagnostics = "1.0.0"
`
