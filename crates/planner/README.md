# crossbuild-planner

Build planner that resolves providers and generates cross-build plans

Part of the [cargo-crossbuild](https://github.com/Moon9t/cargo-crossbuild) workspace — a Cargo-native cross-compilation toolchain manager.

## Installation

`	oml
[dependencies]
crossbuild-planner = "1.0.0"
`
