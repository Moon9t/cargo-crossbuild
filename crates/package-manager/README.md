# crossbuild-package-manager

OS package manager integration for system dependency installation

Part of the [cargo-crossbuild](https://github.com/Moon9t/cargo-crossbuild) workspace — a Cargo-native cross-compilation toolchain manager.

## Installation

`	oml
[dependencies]
crossbuild-package-manager = "1.0.0"
`
